1. Mô tả bài thực hành

Xây dựng một ứng dụng HTTP Server bằng Node.js, sử dụng module http có sẵn. Server được thiết lập chạy tại cổng 3000. Khi người dùng truy cập vào trang chủ, chương trình trả về một trang HTML hiển thị họ tên và mã sinh viên.

2. Công nghệ sử dụng

Node.js

Module HTTP

HTML

Visual Studio Code

3. Cách chạy chương trình

Bước 1: Mở thư mục dự án bằng Visual Studio Code.

Bước 2: Mở Terminal tại thư mục chứa file server.js.

Bước 3: Nhập lệnh node server.js.

Bước 4: Mở trình duyệt và truy cập http://localhost:3000.

Bước 5: Kiểm tra thông tin họ tên và mã sinh viên được hiển thị trên trình duyệt.

4. Kết quả

Chương trình chạy thành công tại cổng 3000. Khi truy cập trang chủ, HTTP Server trả về nội dung HTML hiển thị đầy đủ họ tên và mã sinh viên.
